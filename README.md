# My Claude Skills

Personal Claude Code skills marketplace.

## Install

```
/plugin marketplace add 73156918/claude-skills
```

Then install any skill:

```
/plugin install viral-content-forge
/plugin install research
/plugin install research-add-fields
/plugin install research-add-items
/plugin install research-deep
/plugin install research-report
```

## Skills

| Skill | Description |
|-------|-------------|
| viral-content-forge | Create viral content for Reddit, Twitter/X, LinkedIn, YouTube, TikTok, blogs |
| research | Conduct preliminary research and generate research outline |
| research-add-fields | Add field definitions to existing research outline |
| research-add-items | Add items to existing research outline |
| research-deep | Launch independent agents for deep research on each item |
| research-report | Summarize deep research results into markdown report |
